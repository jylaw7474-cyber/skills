# הגנה על מסמך לפני שליחה במייל

הכלי לוקח קובץ **Word או PDF** ומוציא **PDF רגיל**:
נפתח אצל הנמען כרגיל, בלי סיסמה, בלי התחברות ובלי רשת. אבל:

| פעולה של הנמען | מה קורה |
|---|---|
| סימון טקסט והעתקה | לא יוצא כלום – אין בקובץ טקסט, רק תמונה של כל עמוד |
| המרה ל-Word / חיפוש בטקסט | אין טקסט למצוא |
| כלי AI שקורא את הטקסט של הקובץ | מקבל קובץ ריק מטקסט |
| הדפסה | חסומה בתוכנות שמכבדות את הרשאות ה-PDF (טבלה למטה) |

## התקנה (פעם אחת, ב-Windows)

1. מורידים את קובץ ה-ZIP ופותחים אותו: קליק ימני ← **חלץ הכל**.
   שמים את התיקייה `protect-document` במקום קבוע (למשל "המסמכים שלי").
2. לוחצים פעמיים על **`install.bat`** שבתוך התיקייה.
   הוא מתקין Python אם חסר, מתקין את הספריות הדרושות, ויוצר על שולחן העבודה
   קיצור דרך בשם **Protect document**.
   - אם Windows מציג "Windows protected your PC" – לוחצים **More info** ← **Run anyway**.
   - אם ההתקנה האוטומטית של Python נכשלת: מתקינים Python מ-https://www.python.org/downloads/
     (מסמנים **Add Python to PATH**) ומריצים שוב את `install.bat`.

הכלי ממיר קבצי Word בעזרת ה-Word המותקן במחשב (בעותק נסתר ונפרד – חלונות ה-Word
הפתוחים שלך לא נפגעים). אם אין Word – מתקינים LibreOffice (חינמי) מ-https://www.libreoffice.org.

## שימוש

- **גוררים** קובץ Word או PDF (או כמה קבצים) אל **Protect document** שעל שולחן העבודה.
- או לוחצים עליו פעמיים ובוחרים קבצים.

ליד כל קובץ נוצר קובץ חדש בשם `<שם>_protected.pdf` – אותו שולחים במייל.
המקור לא משתנה. אם כבר קיים קובץ מוגן באותו שם, נוצר `<שם>_protected (2).pdf`.

אפשרויות (משורת הפקודה):
```
python scripts\protect_doc.py חוזה.docx --dpi 150     קובץ קטן יותר
python scripts\protect_doc.py חוזה.docx --dpi 300     חד יותר
```

### מסמך עם "עקוב אחר שינויים" או הערות

אם בקובץ ה-Word יש שינויים במעקב או הערות, הכלי **עוצר** ולא יוצר קובץ –
אחרת המחיקות, הגרסאות הקודמות וההערות היו "נצרבות" לתוך המסמך שנשלח לצד השני.
מאשרים/דוחים את כל השינויים, מוחקים הערות, שומרים ומריצים שוב.
(אם רוצים בכוונה לשלוח עם הסימונים: `--allow-markup`.)

## איפה חסימת ההדפסה וההעתקה עובדת

הקובץ עצמו אף פעם לא מכיל טקסט, ולכן **העתקת טקסט לא תעבוד בשום תוכנה**.
חסימת **ההדפסה** תלויה בתוכנה שבה הנמען פותח את הקובץ:

| תוכנה | הדפסה חסומה? |
|---|---|
| Adobe Acrobat / Reader | כן |
| Google Chrome | כן |
| Microsoft Edge | כנראה כן (מבוסס על אותו מנוע של Chrome / Adobe) |
| Apple Preview (Mac) | כן |
| Firefox | **לא** – מתעלם מההגבלה |
| תצוגה מקדימה ב-Gmail / Google Drive | **כנראה לא** |
| Outlook | תלוי בתוכנת ה-PDF שמותקנת אצל הנמען |
| אייפון / אנדרואיד | לא ידוע |

## מה הכלי לא יכול לחסום – חשוב לדעת

- **צילום מסך / צילום בטלפון** – מה שמופיע על המסך אפשר לצלם.
- **ChatGPT, Claude, Gemini כשמעלים אליהם את ה-PDF עצמו** – הם "מסתכלים" על
  העמוד כתמונה, כמו בן אדם, ולכן יכולים לקרוא גם עמוד שהוא תמונה בלבד.
  הכלי חוסם כלים שקוראים את הטקסט של הקובץ, לא כלים שרואים את התמונה.
- **הדפסה** – בתוכנות שמסומנות "לא" בטבלה, וגם בעזרת כלים להסרת הגבלות.
- הקובץ גדול יותר מהמקור (כ-250–450KB לעמוד), ואי אפשר לחפש בו טקסט.
