# הגנה על מסמך לפני שליחה במייל

הכלי לוקח קובץ **Word או PDF** ומוציא **PDF רגיל**:
נפתח אצל הנמען כרגיל, בלי סיסמה, בלי התחברות ובלי רשת. אבל:

| פעולה של הנמען | מה קורה |
|---|---|
| סימון טקסט והעתקה | לא יוצא כלום – אין בקובץ טקסט, רק תמונה של כל עמוד |
| המרה ל-Word / חיפוש בטקסט | אין טקסט למצוא |
| כלי AI שקורא את הטקסט של הקובץ | מקבל קובץ ריק מטקסט |
| הדפסה | חסומה בתוכנות שמכבדות את הרשאות ה-PDF (ראו טבלה למטה) |

## התקנה (פעם אחת, ב-Windows)

1. מתקינים Python מ-https://www.python.org/downloads/ – בהתקנה מסמנים **Add Python to PATH**.
2. פותחים "שורת הפקודה" (cmd) ומריצים:
   ```
   pip install pymupdf docx2pdf
   ```
   `docx2pdf` משתמש ב-Word המותקן במחשב להמרת קבצי Word. אם אין Word – מתקינים
   LibreOffice (חינמי) מ-https://www.libreoffice.org.

## שימוש

- **גוררים** קובץ (או כמה קבצים) אל `protect.bat`.
- או לוחצים פעמיים על `protect.bat` ובוחרים קבצים.

ליד כל קובץ נוצר קובץ חדש בשם `<שם>_protected.pdf` – אותו שולחים במייל.
את המקור שומרים אצלך.

אפשרויות (משורת הפקודה):
```
python scripts\protect_doc.py חוזה.docx --dpi 150     קובץ קטן יותר
python scripts\protect_doc.py חוזה.docx --dpi 300     חד יותר
```

## מה הכלי לא יכול לחסום – חשוב לדעת

- **צילום מסך / צילום בטלפון** – מה שמופיע על המסך אפשר לצלם.
- **ChatGPT, Claude, Gemini כשמעלים אליהם את ה-PDF עצמו** – הם "מסתכלים" על
  העמוד כתמונה, כמו בן אדם, ולכן יכולים לקרוא גם עמוד שהוא תמונה בלבד.
  הכלי חוסם כלים שקוראים את הטקסט של הקובץ, לא כלים שרואים את התמונה.
- **הדפסה** – החסימה נאכפת על ידי התוכנה שבה פותחים את הקובץ. חלק מהתוכנות
  מתעלמות ממנה (ראו טבלה), וקיימים כלים להסרת ההגבלה.
- הקובץ גדול יותר מהמקור, ואי אפשר לחפש בו טקסט.
